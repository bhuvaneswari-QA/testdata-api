Proof of Concept: Access Test Data via API
This project demonstrates how to access test data through an API, both from the cloud and from a local server using host configuration.
🚀 Hosting Locally
To run the API locally:
vercel dev
This will start a local development server where you can test API endpoints.
you can access the test data locally by 
http://localhost:3000/api/testdata

☁️ Hosting in the Cloud
To host the API in the cloud:
Integrate the project with Vercel via GitHub.
Push your changes to the connected GitHub repository.
Vercel will automatically deploy the API to the cloud.
you can access the test data by
https://testdata-gjavnzmi5-bhuvaneswaris-projects-d4c03d79.vercel.app/api/testdata
